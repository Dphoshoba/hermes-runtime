# Participant Records

This directory holds anonymized usability test records for M9.

## Files

- `P01.json` through `P05.json` — blank participant record templates.
- Each file follows `M9_PARTICIPANT_TEMPLATE.json`.

## Rules

- Use participant IDs only (P01, P02, ...).
- Do **not** record names, emails, or other personally identifying information.
- Each completed record must be filled with **observed** data only.
- Do **not** fabricate or pre-populate observational values.
- Treat completed records as containing potentially sensitive feedback.

## After Testing

Completed records should be aggregated into `M9_RESULTS_SUMMARY_TEMPLATE.json`.
